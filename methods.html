Missing data, and what this file cannot distinguish

The SAV declares no user-missing ranges, and the documented special codes never appear in the released data. IC177Q02JA contains only 1–6; ST438Q04DA only 1–5; PA205Q13DA only 1–5; ST324Q11JA only 1–4; ESCS contains no value with absolute magnitude at or above 10. Every non-substantive response has been collapsed to system missing.

Consequence: not administered, valid skip, invalid and no response cannot be separated in this file. coverage.csv reports observed valid counts and weighted shares against a named denominator — all released records for that country — and reports zero for each special code, because zero is what is there. No country is described as not having administered an item, and no absent module is converted to a zero anywhere in the pipeline.

Inference

The estimand is the equal-weight average of estimates computed separately inside each participating OECD system, which matches OECD's own definition of its average as the arithmetic mean of the respective country estimates. Every result row names its own contributing set; a restricted set is never called "the OECD average".

For one country, with M plausible values and the full-sample estimate in replicate slot zero:

  • Sampling covariance: Fay with 80 replicates and k = 0.5, multiplier 0.05, averaged over plausible values.
  • Imputation covariance: Rubin's (1 + 1/M) times the between-plausible-value covariance. Exactly zero when M = 1, which is the case for questionnaire proportions.
  • Total covariance is the sum of the two.

Independent country designs are then combined as sum_c a_c² · cov_c, with a_c = 1/K by default. This ordering matters and is the reason this release exists in its current form: plausible values are imputed within country, so pairing draw index m across countries is arbitrary. Averaging country estimates plausible-value-by-plausible-value and only then taking the between-draw variance makes the reported standard error depend on that arbitrary ordering. On a synthetic two-country example carrying identical information, reversing one country's plausible-value order moved the aggregate standard error from 4.615 to 4.263 under the earlier arithmetic. Under the corrected combiner it does not move at all. This is covered by a permutation test in the release test suite.

Every statistic vector is multivariate, so contrasts and nested-model differences keep their covariance. Paired changes — raw minus adjusted, baseline minus within-school, one nested model minus the next — are computed inside the joint draws and carry their own interval, rather than being inferred from two separate standard errors.

Intervals are estimate ± 1.96 × SE and are labelled approximate. They describe sampling and plausible-value uncertainty for the systems included. They do not describe a random draw from a universe of countries, and they are not corrected for the number of contrasts examined.

Weighted least squares uses sampling weights multiplying squared residuals; the implementation is checked against an independent numpy.linalg.lstsq reference on the whitened design. Within-school fits subtract weighted school means from the outcome and every non-constant regressor, recomputed for every replicate because the weights change; the implementation is checked against an explicit-indicator fit under unequal weights and with string identifiers carrying leading zeros. Zero-weight schools contribute no weighted records in that replicate and are left unchanged rather than divided by zero.

Weighted quantiles use the inverse weighted empirical CDF with no interpolation: for each probability, the smallest observed value whose cumulative weight share reaches it. Zero-weight records are dropped first. Ties share one cumulative step, so exact quarters are not guaranteed and realised weighted group sizes are reported in ai_checks. In practice they land within 0.03 percentage points of 25% in every system.

Support and exclusion rules

Fixed before estimation, in specification.md:

  1. A system contributes to the primary screen model only if every one of the six exposure

categories has at least 30 records in its analytic sample. This is an analytic stability rule of this analysis, not an OECD rule. No system was excluded by it.

  1. A rank-deficient weighted design raises an error carrying country, model and replicate.

The affected estimate would be published with status = unsupported, a reason and no number. It is never returned as zero or NaN. No fit failed.

  1. Every group mean requires positive weight in every replicate, in every system of the

fixed country set. If any system fails, the fixed-set score mean is published as unsupported with a reason rather than recomputed on a smaller set — and the response shares, which are independent of score support, are reported for the full fixed set regardless. Score-mean rows carry their own counted n_students per response group; share rows carry the response denominator.

  1. Sparse cells in the descriptive AI distribution are flagged with counts and kept

visible. The smallest cell was 37, so none was flagged.

Checking the numbers

The analysis code is not public. Every aggregate table behind the article is, in the data downloads, and claims.json maps each number in the article to the generated result row it came from, so any figure here can be traced to its table without the 2 GB source file. Regenerating the tables themselves requires the PISA microdata, obtained from the OECD.

Excluded from this release

Deliberately not published here, and not to be inferred from anything above: mixed-task process, attention or patience claims from the timing data; forecasts of any kind; migration and management arguments; school-policy effects; and decile heat maps built on averaged plausible values. The underlying investigations remain in the project's history for follow-up, but they do not meet the standard applied to this release.
